Common Git Commands:

1. git init - Initialize a new Git repository
2. git add . - Add all files to the staging area
3. git add <file> - Add a specific file to the staging area
4. git commit -m "message" - Commit changes with a message
5. git status - Check the status of the working directory and staging area
6. git log - View commit history
7. git branch - List branches
8. git branch <name> - Create a new branch
9. git checkout <branch> - Switch to a branch
10. git merge <branch> - Merge a branch into the current branch
11. git push origin <branch> - Push changes to a remote repository
12. git pull origin <branch> - Pull changes from a remote repository
13. git clone <url> - Clone a repository from a URL
14. git remote -v - List remote repositories
15. git remote add origin <url> - Add a remote repository
16. git diff - Show differences between working directory and staging area
17. git reset --hard <commit> - Reset to a specific commit
18. git stash - Stash changes temporarily
19. git stash pop - Apply stashed changes
20. git tag <tag> - Create a tag
